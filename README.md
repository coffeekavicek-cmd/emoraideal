# EMORA Premium V6

Interactive emotional mini-site platform demo.

## Product model
- **Shablon — 49 990 so'm**
- **EMORA AI — 69 990 so'm**

EMORA AI is intentionally restricted to supported emotional/event categories. It is not a business/portfolio/general website builder.

## Categories
1. Tug'ilgan kun
2. Uzr so'rash
3. Taklifnoma
4. Sevgi / romantika
5. Yillik sana
6. Rahmat
7. Turmush qurish taklifi
8. To'y / nikoh
9. Maxsus kunlar

Each category exposes 10 interactive concepts. The current build contains reusable interaction engines such as runaway buttons, scratch reveals, sliders, tap-to-unlock grids, countdowns, hold-to-open, card reveals and celebration effects.

## Customer flow
Category → plan → template → edit & media → full preview → Click/Payme demo payment → automatic public link.

## Run locally
```bash
npm install
npm start
```

Open http://localhost:3000 (or the port printed by the server).

## Demo payments
Click and Payme are simulated when `DEMO_MODE=true`; no real money is charged.
