# EMORA Premium V7

Rebuilt premium frontend focused on emotional interactive mini-sites.

## Product model
- Template — 49,990 UZS
- EMORA AI — 69,990 UZS
- 9 supported occasions only; no portfolio/business/CV builder.
- 10 concepts per occasion (90 total).

## Core flow
Occasion -> plan -> interactive template -> edit/media -> full preview -> Click/Payme demo -> unique public link.

## Interactive mechanics
Runaway buttons, sliders, scratch reveals, balloon/tap pops, hold-to-unlock, countdown, flip/reveal cards, confetti and media scenes.

## Languages
UZ / RU / EN interface. Published project preserves selected language.

## Railway
The server uses process.env.PORT automatically. In demo mode set DEMO_MODE=true. Generate a service domain after a successful deployment.
